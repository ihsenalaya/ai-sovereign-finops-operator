# Article 3

Workspace de travail pour l'article scientifique sur GOV-AR.

Ce répertoire contient :
- l'audit complet de l'opérateur existant ;
- la revue bibliographique ;
- la conception de GOV-AR ;
- l'infrastructure de reproduction ;
- les expériences ;
- les analyses ;
- les artefacts de soumission.

Règles de travail :
- ne pas modifier `article1/` ni les résultats historiques sauf nécessité sur le code partage ;
- journaliser toute déviation de protocole ;
- rattacher chaque claim à une preuve tracable.
